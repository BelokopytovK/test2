# Desktop Organizer - Приложение для организации файлов на рабочем столе

## Описание

Приложение для рабочего стола, которое компонует ярлыки, папки и файлы в выпадающие меню с автоматической категоризацией.

## Возможности

- 🗂️ **Автоматическая категоризация файлов**:
  - Ярлыки (.lnk, .url)
  - Документы (.txt, .doc, .docx, .pdf)
  - Таблицы (.xls, .xlsx, .csv)
  - Презентации (.ppt, .pptx)
  - Изображения (.jpg, .png, .gif)
  - Видео (.mp4, .avi, .mkv)
  - Аудио (.mp3, .wav, .flac)
  - Архивы (.zip, .rar, .7z)
  - Приложения (.exe, .bat, .sh)
  - Код (.py, .js, .html, .css)
  - Папки

- 🔍 **Умное меню**:
  - При малом количестве файлов (< 10) - простое подменю
  - При большом количестве - алфавитная группировка

- ⚙️ **Настройки**:
  - Добавление/удаление отслеживаемых папок
  - Сохранение конфигурации в файле `~/.desktop_organizer.conf`
  - Автоматическое обновление при изменении файлов

- 🔔 **Системный трей**:
  - Иконка в системном трее
  - Быстрый доступ к файлам через контекстное меню
  - Уведомления о запуске

## Требования

- Python 3.6+
- PyQt5

## Установка

```bash
pip install PyQt5
```

## Запуск

```bash
python desktop_organizer.py
```

## Использование

1. После запуска приложение появится в системном трее
2. Щелкните на иконку в трее для открытия меню
3. Файлы автоматически распределяются по категориям
4. Щелкните на файл в меню для его открытия
5. Через меню "Настройки папок" можно добавить новые папки для отслеживания

## Конфигурация

Файл конфигурации: `~/.desktop_organizer.conf`

Каждая строка содержит путь к отслеживаемой папке. По умолчанию отслеживается папка Desktop или домашняя директория.

## Примечания

- На Windows используется `os.startfile()` для открытия файлов
- На Linux/Mac используется `xdg-open` для открытия файлов
- Приложение работает в фоновом режиме через системный трей
- Автоматическое обновление меню каждые 5 секунд
